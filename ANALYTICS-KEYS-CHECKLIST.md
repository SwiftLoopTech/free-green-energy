# Tracking Keys Checklist

Collect these values before we inject live tracking across the site.

## Google

```text
GTM_CONTAINER_ID=
GA4_MEASUREMENT_ID=
GA4_PROPERTY_ID=
GA4_WEB_STREAM_NAME=
GOOGLE_SEARCH_CONSOLE_VERIFICATION_TAG=
GOOGLE_ADS_CONVERSION_ID=
GOOGLE_ADS_CONVERSION_LABEL=
```

## Microsoft

```text
MICROSOFT_CLARITY_PROJECT_ID=
```

## Business and Attribution

```text
PRIMARY_DOMAIN=https://fgesolar.in
PRIMARY_CONTACT_NUMBER=
PRIMARY_WHATSAPP_NUMBER=
PRIMARY_CONTACT_EMAIL=
GOOGLE_BUSINESS_PROFILE_URL=
FACEBOOK_PAGE_URL=
INSTAGRAM_PROFILE_URL=
LINKEDIN_COMPANY_URL=
YOUTUBE_CHANNEL_URL=
```

## Notes

- `GTM_CONTAINER_ID` starts with `GTM-`
- `GA4_MEASUREMENT_ID` starts with `G-`
- `GOOGLE_SEARCH_CONSOLE_VERIFICATION_TAG` is only the value inside `content=""`
- `MICROSOFT_CLARITY_PROJECT_ID` is the short project key used in the Clarity script
- If you are not running ads right now, keep the Google Ads fields blank
